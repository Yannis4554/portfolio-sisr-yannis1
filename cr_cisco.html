Ref 1.5 - Mettre à disposition un service

SWITCH CISCO — CLI & SSH

Octobre 2025 · Switch Cisco Catalyst · Cisco IOS

📋 Contexte

Un switch permet de connecter tous les postes d'un réseau. Sans configuration, tout le monde est sur le même réseau. Les VLANs séparent les flux par service (administration, utilisateurs, serveurs). SSH sécurise l'administration à distance en chiffrant la connexion (contrairement à Telnet qui envoie les mots de passe en clair).

🖧 1. Architecture VLANs

graph TB subgraph SWITCH["🔀 Switch Cisco"] P1["Ports Fa0/1-4"] --> V10 P2["Ports Fa0/5-12"] --> V20 P3["Ports Fa0/13-16"] --> V30 TRUNK["Port Gi0/1 — TRUNK"] --> ROUTEUR end V10["🔴 VLAN 10 — Admin"] V20["🟢 VLAN 20 — Utilisateurs"] V30["🟣 VLAN 30 — Serveurs"] ROUTEUR["🖧 Routeur — Inter-VLAN"]

⚙️ 2. Configuration des VLANs — Commandes CLI

Création des VLANs et affectation des ports :

SW-Yannis — Console Cisco IOS
! --- Création des VLANs ---
SW-Yannis(config)# vlan 10
SW-Yannis(config-vlan)# name ADMIN
SW-Yannis(config-vlan)# exit
SW-Yannis(config)# vlan 20
SW-Yannis(config-vlan)# name UTILISATEURS
SW-Yannis(config-vlan)# exit
SW-Yannis(config)# vlan 30
SW-Yannis(config-vlan)# name SERVEURS
SW-Yannis(config-vlan)# exit

! --- Affectation des ports au VLAN 10 (Admin) ---
SW-Yannis(config)# interface range FastEthernet 0/1 - 4
SW-Yannis(config-if-range)# switchport mode access
SW-Yannis(config-if-range)# switchport access vlan 10
SW-Yannis(config-if-range)# exit

! --- Affectation des ports au VLAN 20 (Utilisateurs) ---
SW-Yannis(config)# interface range FastEthernet 0/5 - 12
SW-Yannis(config-if-range)# switchport mode access
SW-Yannis(config-if-range)# switchport access vlan 20
SW-Yannis(config-if-range)# exit

! --- Affectation des ports au VLAN 30 (Serveurs) ---
SW-Yannis(config)# interface range FastEthernet 0/13 - 16
SW-Yannis(config-if-range)# switchport mode access
SW-Yannis(config-if-range)# switchport access vlan 30
SW-Yannis(config-if-range)# exit

! --- Configuration du port Trunk vers le routeur ---
SW-Yannis(config)# interface GigabitEthernet 0/1
SW-Yannis(config-if)# switchport mode trunk
SW-Yannis(config-if)# switchport trunk allowed vlan 10,20,30
SW-Yannis(config-if)# exit

🔒 3. Sécurisation SSH — Commandes CLI

SW-Yannis — Sécurisation SSH
! --- Configuration de base ---
SW-Yannis(config)# hostname SW-Yannis
SW-Yannis(config)# ip domain-name yannis.local

! --- Génération de la clé RSA pour SSH ---
SW-Yannis(config)# crypto key generate rsa modulus 2048
The name for the keys will be: SW-Yannis.yannis.local
% Generating 2048 bit RSA keys... [OK]

! --- Activation de SSH version 2 ---
SW-Yannis(config)# ip ssh version 2

! --- Autoriser UNIQUEMENT SSH (pas Telnet) ---
SW-Yannis(config)# line vty 0 4
SW-Yannis(config-line)# transport input ssh
SW-Yannis(config-line)# login local
SW-Yannis(config-line)# exit

! --- Désactiver l'interface web (source de failles) ---
SW-Yannis(config)# no ip http server
SW-Yannis(config)# no ip http secure-server
  • crypto key generate rsa 2048 : crée la clé de chiffrement pour SSH
  • transport input ssh : seul SSH est autorisé (Telnet bloqué)
  • no ip http server : l'interface web est désactivée pour éviter les failles

📋 4. Vérification

SW-Yannis — Vérification des VLANs
SW-Yannis# show vlan brief

VLAN Name Status Ports
---- ---- ------ -----
1 default active
10 ADMIN active Fa0/1, Fa0/2, Fa0/3, Fa0/4
20 UTILISATEURS active Fa0/5, Fa0/6, Fa0/7, Fa0/8, Fa0/9, Fa0/10, Fa0/11, Fa0/12
30 SERVEURS active Fa0/13, Fa0/14, Fa0/15, Fa0/16

✅ Résultats

  • 3 VLANs créés et ports affectés en mode access
  • Port trunk configuré vers le routeur
  • SSHv2 activé avec clé RSA 2048 bits
  • Telnet et interface web désactivés
