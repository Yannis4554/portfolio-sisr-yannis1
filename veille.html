Stage 2ème année — Proxy Squid (Armée de l'Air)

Janvier–Février 2026 · 5 semaines · Base Aérienne 123 de Bricy

📋 Contexte

L'Armée de l'Air a détecté que certains militaires accédaient à des sites interdits (terrorisme, pornographie, jeux en ligne) depuis leurs postes de travail pendant les heures de service. Ma mission : déployer un proxy de filtrage web sur Debian 13 pour bloquer ces accès.

⚙️ Configuration squid.conf

# Définition des ACL
acl sites_interdits dstdomain "/etc/squid/blacklist.txt"
acl reseau_local src 192.168.0.0/16

# Règles de filtrage
http_access deny sites_interdits
http_access allow reseau_local
http_access deny all

# Port d'écoute
http_port 3128

# Journalisation
access_log /var/log/squid/access.log

La blacklist (/etc/squid/blacklist.txt) contient la liste des domaines fournie par l'Armée, classés par catégorie. Chaque tentative d'accès à un site bloqué est journalisée dans access.log.

✅ Résultats

  • Proxy Squid opérationnel sur Debian 13
  • Blacklist de l'Armée intégrée et testée
  • Journalisation des tentatives de connexion bloquées
  • Déploiement en production sur le réseau de la base aérienne
  • Documentation technique complète rédigée
