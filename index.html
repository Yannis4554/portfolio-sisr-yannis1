PROJET 01 / 05
2024 — 2025

Active Directory & DNS Redondant — Labannu / Labannubis

Déploiement d'une infrastructure AD complète sur Nutanix avec 2 contrôleurs de domaine en réplication. DNS primaire et secondaire pour la haute disponibilité. Création d'utilisateurs, groupes, UO et validation depuis postes clients.

Windows Server Active Directory DNS primaire DNS secondaire Nutanix GPO

Serveur Labannu (192.168.250.98) — Contrôleur de domaine principal (DC1). Installation du rôle AD DS, configuration du domaine, création des UO, comptes utilisateurs et groupes de sécurité. Serveur DNS primaire pour la résolution interne.

Serveur Labannubis (192.168.250.100) — Contrôleur de domaine secondaire (DC2). En cas de panne de Labannu, Labannubis prend le relais sans interruption de service grâce à la réplication AD DS et au DNS secondaire.

Validation finale : connexion réussie depuis un poste client Windows 10/11 avec les comptes créés dans l'Active Directory.

DC1 Labannu → 192.168.250.98 (DNS primaire)
DC2 Labannubis → 192.168.250.100 (DNS secondaire)
Réplication AD DS → automatique bidirectionnelle
Zone DNS → labannu.local (zone secondaire sur DC2)
Rôles FSMO → DC1 (PDC, RID, Infra, Schema, Naming)

Serveur DHCP — Debian 12

Installation et configuration d'un serveur DHCP sous Debian 12 avec isc-dhcp-server. Définition des plages, réservations MAC, options de bail, DNS et passerelle. Validation avec attribution automatique depuis les postes clients.

Debian 12 isc-dhcp-server IPv4 Linux Réseau local

Déploiement sur Debian 12 via apt install isc-dhcp-server. Configuration du fichier /etc/dhcp/dhcpd.conf : subnet, plage dynamique, bail de 24h, option routers (passerelle), option domain-name-servers (DNS). Activation de l'interface dans /etc/default/isc-dhcp-server. Vérification des attributions via /var/lib/dhcp/dhcpd.leases.

Configuration avancée en ligne de commande IOS : segmentation VLAN, routage inter-VLAN, trunk/access. Sécurisation complète de l'administration distante via SSHv2 avec clés RSA 2048 bits et restrictions ACL.

Cisco IOS SSHv2 VLAN ACL CLI Sécurité

PROJET 04 / 05
11/2025

Haute Disponibilité — Keepalived & LVS

Architecture haute disponibilité complète sur Nutanix : 2 directeurs LVS en MASTER/BACKUP, IP virtuelle VRRP, 2 serveurs web avec synchronisation rsync. Basculement automatique en cas de panne du nœud principal.

Keepalived LVS / IPVS VRRP rsync Debian 12 Nutanix

Architecture : Le Directeur MASTER (priorité 100) distribue les requêtes entre les 2 serveurs web via Round Robin NAT. En cas de panne, le BACKUP (priorité 80) récupère automatiquement l'IP virtuelle grâce à VRRP. Les serveurs web synchronisent leurs données via rsync pour assurer la cohérence.

Validation : Le client accède au site via 172.31.1.70 (VIP). Même après extinction du MASTER, le service reste disponible sans interruption.

Analyse de Trames & Audit Wireshark

Capture et analyse de trames réseau avec Wireshark sur un réseau simulé. Identification d'anomalies, détection de flux suspects, filtrage par protocole, et rédaction d'un rapport d'audit complet avec recommandations.

Wireshark TCP/IP Audit sécurité ARP Cybersécurité

Mise en place d'une session de capture sur interface réseau. Filtres appliqués : arp, icmp, tcp.port==80, dns. Analyse des anomalies détectées : requêtes ARP suspectes, connexions non autorisées, ports inhabituels. Rédaction d'un rapport avec recommandations de sécurisation (désactivation protocoles inutiles, renforcement pare-feu).
