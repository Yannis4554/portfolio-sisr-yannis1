Ref 1.5 - Mettre à disposition un service

Serveur DHCP — Debian 12

Mars 2025 · OS : Debian 12 · Paquet : isc-dhcp-server

📋 Contexte

Quand un nouvel ordinateur se connecte au réseau, il a besoin d'une adresse IP pour communiquer. Sans serveur DHCP, il faudrait configurer chaque poste manuellement. L'objectif : automatiser tout ça avec un serveur DHCP sous Debian 12.

🖧 1. Réseau et rôle du serveur DHCP

Le serveur DHCP distribue automatiquement les adresses IP aux postes qui se connectent. L'imprimante a une réservation — elle reçoit toujours la même IP grâce à son adresse MAC.

🔄 2. Comment ça marche — le processus DORA

Quand un poste se connecte au réseau, il échange 4 messages avec le serveur DHCP :

sequenceDiagram participant PC as 🖥️ Nouveau poste (pas d'IP) participant SRV as 🐧 Serveur DHCP PC->>SRV: 1️⃣ DISCOVER — "Y a quelqu'un ?" SRV-->>PC: 2️⃣ OFFER — "Tiens, prends 192.168.X.50" PC->>SRV: 3️⃣ REQUEST — "OK je la prends !" SRV-->>PC: 4️⃣ ACK — "C'est validé, bail de 24h ✅"

⚙️ 3. Configuration

Le fichier de configuration principal est /etc/dhcp/dhcpd.conf :

subnet 192.168.X.0 netmask 255.255.255.0 {
  range 192.168.X.50 192.168.X.200;
  option routers 192.168.X.254;
  option domain-name-servers 192.168.250.98;
  default-lease-time 86400;
}
  • range : les adresses IP disponibles pour les clients
  • option routers : la passerelle (pour accéder à Internet)
  • option domain-name-servers : le serveur DNS (Labannu)
  • default-lease-time : durée du bail — 24 heures

✅ Résultats

  • Serveur DHCP opérationnel sur Debian 12
  • Les postes reçoivent automatiquement une IP dès qu'ils se connectent
  • Baux vérifiés dans /var/lib/dhcp/dhcpd.leases
