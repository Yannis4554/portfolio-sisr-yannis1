Sécurité & Transfert

Hébergement Wampserver et configuration FileZilla

Installation de Wampserver sur un serveur Windows afin d’héberger des applications web. La seconde partie consistait à mettre en place un serveur FTP avec FileZilla Server : création d’un utilisateur, définition des droits (lecture, écriture) et choix d’un répertoire partagé. Un port range personnalisé a été défini et ouvert dans le pare‑feu Windows pour les connexions sécurisées.

  • Wampserver
  • FileZilla Server
  • Pare-feu Windows
